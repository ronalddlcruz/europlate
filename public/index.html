Rol y tipo de producto
Define cómo se usa en el sistema y si tendrá una o varias presentaciones.
Se descuenta del stock al confirmar la orden. Desmarca solo si este insumo se comparte entre varias órdenes (ej. bobinas).
Tipo de producto
3
Atributos de las presentaciones
Cada atributo (ej. gramaje, largo) se solicita al crear una variante.
Acompañará al valor en el nombre. Ej: 120cm, 350gr
Cuando esté activo, el subtotal de la línea de Importación / Compra = valor de este atributo × Costo Unit.
Ejemplo: si este atributo es "Peso (kg)" con valor 650 y el Costo Unitario es 0.75, el Subtotal = 650 × 0.75 = 487.50.
